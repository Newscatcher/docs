`/search` returns the best articles for a question. `/articles` returns every
article that matches a boolean query, newest first, so you can page through
them. It searches the last 12 months.

| | `/search` | `/articles` |
|---|---|---|
| Query | Plain words or keywords | Boolean query |
| Results | The best `limit` articles, grouped into stories | Every match, up to the first 1,000 per query |
| Time window | Up to the last 30 days | Up to the last 365 days |
| Order | Relevance by default | Newest first by default |
| Each result | Headline, summary, story and more | Headline, publisher, date, language, country and a snippet |
| Credits | By [effort](/news/effort-levels) | 5 NCC per page |

## Your first request

Send the parameters as a JSON body to `POST /articles`:

```bash
curl -X POST "https://api.newscatcherapi.com/news-api/articles" \
  -H "x-api-key: $NEWSCATCHER_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "q": "\"interest rate\" AND (cut OR hike) NOT crypto",
    "from_date": "2026-10-03",
    "page_size": 100
  }'
```

`GET /articles` takes the same parameters in the query string. List parameters
are comma-separated strings in both; in the JSON body they can also be arrays.

## Writing the query

`q` is required and up to 1,000 characters long. It takes:

| Syntax | Example | Matches |
|---|---|---|
| `AND`, `OR`, `NOT` | `Tesla AND recall NOT Cybertruck` | Articles with both words, without the third |
| Parentheses | `"interest rate" AND (cut OR hike)` | Groups of terms |
| `"exact phrase"` | `"Silicon Valley Bank"` | The words in this order |
| `+must`, `-mustnot` | `+Tesla -Musk` | Articles that must have, or must not have, a word |
| Wildcards | `regulat*` | `regulator`, `regulation`, `regulatory` |
| `NEAR` | `NEAR("rate", "decision", 5)` | The words within 5 words of each other |

A query that is only a wildcard, such as `*`, is refused with `422`.

`search_in` sets where `q` is searched, with at most 2 values:

| `search_in` | Searches |
|---|---|
| `title_body` (default) | The headline and the body |
| `title` | The headline |
| `body` | The body |
| `summary` | The summary |
| `title_translated`, `body_translated`, `title_body_translated`, `summary_translated` | The same fields in their English translation |

When `search_in` searches a translated field, each result also has `title_en`,
the English headline.

## Time window

`from_date` and `to_date` set the window. Both take ISO 8601 (`2026-10-03`,
`2026-10-03T14:00:00`, with or without an offset; UTC otherwise) or a phrase
such as `7 days ago`.

- `from_date` defaults to midnight 7 days ago. It can go up to 365 days back,
  or up to your plan's history for `/articles`. An earlier `from_date` is cut
  to it, and the response says `"clamped": true` in `window`.
- `to_date` defaults to the moment of the request.

## Paging through the results

A page holds up to 100 articles (`page_size`, default 100). A query reaches
its first 1,000 articles: `page` × `page_size` can be at most 1,000. A deeper
page is refused with `422`. To reach more articles, narrow the query or split
the window.

The response returns the end of the window in `window.to`. Send it back as
`to_date` when you ask for the next page, so that every page covers the same
articles:

```bash
curl -X POST "https://api.newscatcherapi.com/news-api/articles" \
  -H "x-api-key: $NEWSCATCHER_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "q": "\"interest rate\" AND (cut OR hike) NOT crypto",
    "from_date": "2026-10-03",
    "to_date": "2026-11-02T16:00:00+00:00",
    "page": 2,
    "page_size": 100
  }'
```

## Filters and sorting

| Parameter | What it does |
|---|---|
| `languages`, `not_languages` | Keep or leave out languages: ISO 639-1 codes. `zh` means both `cn` and `tw`. |
| `countries`, `not_countries` | Keep or leave out publishers' countries: ISO 3166-1 alpha-2 codes. Ignored when `sources` is set. |
| `sources`, `not_sources` | Keep or leave out publishers by domain, for example `reuters.com`. |
| `predefined_sources` | The best-ranked publishers of a country or of the world: `top 100 US`, `top 50 global`. |
| `ranked_only`, `from_rank`, `to_rank` | Only publishers that have a traffic rank, or a range of ranks (1 is the best). |
| `word_count_min`, `word_count_max` | Only articles with this many words. |
| `exclude_duplicates` | Leave out copies of an article that another publisher published first. Off by default. Needs a window that starts after 2024-05-13 with `languages=en`, and after 2025-03-17 otherwise. |
| `sort_by` | `published_at` (default) newest first, `-published_at` oldest first, `relevancy` best match first, `rank` best-ranked publisher first. |

List parameters take at most 100 values. A blank value, the same value in a
filter and its `not_` filter, or `from_rank` greater than `to_rank` is refused
with `422`.

## What comes back

```json
{
  "query": "\"interest rate\" AND cut",
  "search_in": ["title_body"],
  "sort_by": "published_at",
  "took_ms": 412,
  "window": {
    "from": "2026-10-03T00:00:00+00:00",
    "to": "2026-11-02T16:00:00+00:00"
  },
  "page": 1,
  "page_size": 100,
  "total_hits": 4812,
  "total_pages": 10,
  "count": 1,
  "results": [
    {
      "id": "219ba6eb51d067e58b0941c8f07cfc1d",
      "title": "Fed officials signal patience on further rate cuts",
      "url": "https://www.reuters.com/markets/us/fed-officials-signal-patience-further-rate-cuts-2026-11-02/",
      "source": { "domain": "reuters.com", "name": "Reuters" },
      "published_at": "2026-11-02T14:05:00+00:00",
      "author": "Howard Schneider",
      "language": "en",
      "country": "US",
      "rank": 104,
      "image_url": "https://www.reuters.com/resizer/photo.jpg",
      "snippet": "Federal Reserve officials on Monday said they were in no hurry to lower interest rates again, pointing to a labor market that remains firm and inflation that has…",
      "word_count": 812,
      "score": 12.4
    }
  ]
}
```

| Field | What it tells you |
|---|---|
| `total_hits` | The exact number of articles that match in the window. |
| `total_pages` | The pages you can read: the first 1,000 matches divided by `page_size`, rounded up. |
| `count` | The number of articles on this page. `0` when nothing matched. |
| `window` | The window that was searched. `clamped` is `true` when `from_date` was cut to your plan's history. |
| `snippet` | The start of the publisher's description, cut at a word boundary (200 characters by default). |
| `rank` | The publisher's traffic rank. `999999` means the publisher has no rank. |
| `score` | Relevance to `q`. Only the order is meaningful, not the value. |

## Credits and limits

- A successful call (`200`) costs 5 NCC, whatever the page size or the number
  of results, also when nothing matches. A refused or failed request is not
  charged.
- Your plan sets the page size, the number of pages, the history and the
  requests per second for `/articles`. Check the `articles` field of
  [`GET /subscription`](/get-started/rate-limits#check-your-plan). A larger
  page than your plan allows is refused with `403`.
- The parameters of the Enterprise v3 search, such as `theme` or
  `iptc_tags`, are refused with `403`. Any other unknown parameter gets `422`.
- A search that runs out of time gets `408`. Narrow the window, use a smaller
  `page_size` or simplify the query.
