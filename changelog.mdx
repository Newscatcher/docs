<Update label="November 9, 2026" description="Agent 1.7.0">
  ## Clearer progress messages

  - **Progress**: when a search query is too long to show in full in a
    progress message, it now ends with `…`, so you can tell it was shortened.
    The search itself always uses the whole query. See
    [Follow a run live](/agent/runs#follow-a-run-live).
  - **Removed**: the `conversation_id` field of `POST /monitors` and of monitor
    responses. It had no effect, and the API now ignores it. See
    [Monitors](/agent/monitors).
  - **Fixed**: a query that contains quoted phrases now shows exactly as you
    wrote it in progress messages.
</Update>

<Update label="November 4, 2026" description="Agent 1.5.0">
  ## Company monitor price

  - **Company monitors**: following a company now costs about $3 per company per
    month (was $1.50). Event monitors, event research and company research
    prices do not change. See
    [Credits and pricing](/get-started/credits-and-pricing#agent).
</Update>

<Update label="November 4, 2026" description="News API 1.1.0">
  ## Articles

  - **`/articles`**: list every article that matches a boolean query over the
    last 12 months, newest first, and page through up to the first 1,000
    matches. Each call costs 5 NCC. See
    [Articles](/news/articles).
  - **Plan limits**: `GET /subscription` now returns an `articles` field with
    the page size, depth, history, requests per second and price of
    `/articles`. See [Rate limits](/get-started/rate-limits#check-your-plan).
  - **New error status**: `408` when an `/articles` search runs out of time. It
    is not charged. See [Errors](/get-started/errors).
  - **Fixed**: when a part of the service does not answer in time, you now get
    `503` with a `Retry-After` header instead of `500`. The request is not
    charged and does not count toward your daily request limit. See
    [Errors](/get-started/errors).
</Update>

<Update label="October 30, 2026" description="Launch">
  ## New News API and Agent

  - **News API**: `/search` ranks the last 30 days of news in every language,
    groups results into stories and summarizes each article, at three
    [effort levels](/news/effort-levels).
  - **Stories**: `/stories/{story_id}` lists every article of one story.
  - **Agent**: research events or companies in the background and get a
    table, once or on a schedule with [monitors](/agent/monitors).
  - The News API, the Web Search API and the Local News API docs move under
    **Enterprise** in the version menu.
</Update>
